## 자동 수집 상태

평일 20:15 KST Supabase Cron → GitHub workflow_dispatch → KIND 수집 → Supabase 저장 구조를 유지한다.

`record_collection_status.py`가 앞으로 실행되는 workflow의 시작·성공·실패 상태를 기록한다. 성공 시 저장 건수는 신규 삽입 수가 아니라 해당 날짜 DB 전체 건수다. 상태 기록 장애는 본 수집을 중단시키지 않고 Actions 경고를 남긴다.

기존 날짜에 완료 기록을 소급해 만들지 않았다. 기록이 없는 날짜는 확인 불가, 30분을 넘긴 미완료 기록은 확인 필요로 표시한다. 수집 이후 등록된 공시는 1회 수집 결과에 포함되지 않을 수 있다. 첫 예약 실행에서 실제 기록을 추가 검증해야 한다.
